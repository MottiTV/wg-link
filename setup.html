Set up WG-Link

For server admins, after WG-Link has joined the Discord. 24 September 2026.

Do this once. You need Manage Server or Administrator. When these steps are saved, the bot is ready. Each member still links their own Wargaming account.

1. Allow the bot to work

When you invite WG-Link, Discord asks you to grant access. Accept that screen.

The bot needs permission to view channels, send messages, embed links, read message history, manage roles, and manage nicknames. Without Manage Roles and Manage Nicknames it cannot give the linked role or set server nicknames.

2. Move the bot’s own role up

Open Server Settings, then Roles.

Discord creates a role for the bot, usually named WG Link. Drag that role well up the list. Roles higher in the list are stronger.

Put it above the verified role from the next step, and above the members whose nicknames should change. A normal place is under the server owner and your Admin role, and above Mods, VIP, and everyone else.

The bot can rename members only when their highest role sits below the bot role. It can never rename the server owner.

3. Create the role members will receive

Create a new role for people who link a Wargaming account. The name is yours. WG-Linked is a clear example.

This is a normal role. It is separate from the bot’s own role. Do not use the bot role as the verified role.

Members receive it after they finish linking, either with /link start or with the button posted later by /link-panel. Both start the same link.

4. Place that role so it does not cover important colors

Drag WG-Linked below the colored roles you want to keep visible, such as VIP, Mods, Supporter, or Nitro.

Discord colors a member’s name with their highest role that has a color. If WG-Linked sits above VIP and has its own color, a linked VIP shows the WG-Linked color instead of VIP.

Keep WG-Linked below the bot role as well. If it is above the bot, the bot cannot assign it.

A safe order, from top to bottom:

  1. Server owner
  2. Admin
  3. WG Link (the bot)
  4. Staff and colored roles you care about (Mods, VIP, and similar)
  5. WG-Linked
  6. Everyone else

5. Open the Command Center and save Setup

In your server, run /admin or /link-setup web. Only you can see the reply. Open the link and sign in with Discord.

Go to Setup. For your server the page is:

https://bot-production-a210.up.railway.app/admin/<your-server-id>/setup

The command already opens the right server. You do not need to type the address yourself.

Set these, then click Save:

  • Verified role. The role from step 3, for example WG-Linked.
  • Nickname style. How a linked name looks on your server. The choices are [TAG] Player (EU), Player (EU), [TAG] Player, or the name only.
  • Welcome DM. Turn it on or off. When a member joins this Discord. Not the DM after /link start.
  • Link DM. A private message after /link start succeeds, with the Wargaming account, the server nickname, and the verified role.
  • Unlink DM. A private message after /link unlink, confirming that the link was removed.
  • Fallback channel. Used when that member has DMs closed.

Save and update nicks is for later, when you change the nickname style and want existing linked members renamed right away.

The same settings also exist in Discord as /link-setup role and /link-setup options. Check them any time with /link-setup status.

6. Post a link button for members

This step is optional. In the channel where members should find it, run /link-panel.

WG-Link posts a message with a button. That button starts the same link as /link start.

WG-Link is ready

Nothing else is required for a normal setup.

Each member decides whether to link. They use /link start or the panel button, pick EU, NA, or ASIA, and sign in with Wargaming. When that finishes, they receive the verified role and, when Discord allows it, a server nickname such as [GURKA] Player (EU).

The reply is private. Only that member can see it. It shows the linked account, the server nickname, and /link unlink if they want to remove the link.

Until a member does this, they stay unlinked and do not get the role.

WG-Link einrichten

Für Server-Admins, nachdem WG-Link dem Discord beigetreten ist. 24. September 2026.

Das machst du einmal. Du brauchst Server verwalten oder Administrator. Wenn diese Schritte gespeichert sind, ist der Bot bereit. Jedes Mitglied verknüpft weiterhin sein eigenes Wargaming-Konto.

1. Dem Bot die Arbeit erlauben

Wenn du WG-Link einlädst, fragt Discord nach dem Zugriff. Diesen Bildschirm akzeptierst du.

Der Bot braucht die Rechte, Kanäle zu sehen, Nachrichten zu senden, Links einzubetten, den Nachrichtenverlauf zu lesen, Rollen zu verwalten und Nicknames zu verwalten. Ohne Rollen verwalten und Nicknames verwalten kann er die verknüpfte Rolle nicht vergeben und keine Server-Nicknames setzen.

2. Die eigene Rolle des Bots nach oben ziehen

Öffne Servereinstellungen, dann Rollen.

Discord legt eine Rolle für den Bot an, meist mit dem Namen WG Link. Ziehe diese Rolle weit nach oben. Rollen weiter oben in der Liste sind stärker.

Setze sie über die Verified-Rolle aus dem nächsten Schritt und über die Mitglieder, deren Nicknames sich ändern sollen. Ein normaler Platz ist unter dem Server-Inhaber und deiner Admin-Rolle, und über Mods, VIP und allen anderen.

Der Bot kann Mitglieder nur umbenennen, wenn deren höchste Rolle unter der Bot-Rolle liegt. Den Server-Inhaber kann er nie umbenennen.

3. Die Rolle anlegen, die Mitglieder bekommen

Lege eine neue Rolle für Leute an, die ein Wargaming-Konto verknüpfen. Den Namen bestimmst du. WG-Linked ist ein klares Beispiel.

Das ist eine normale Rolle. Sie ist getrennt von der eigenen Rolle des Bots. Benutze die Bot-Rolle nicht als Verified-Rolle.

Mitglieder bekommen sie, nachdem die Verknüpfung fertig ist, entweder mit /link start oder mit dem Button, den /link-panel später postet. Beides startet dieselbe Verknüpfung.

4. Die Rolle so setzen, dass sie wichtige Farben nicht überdeckt

Ziehe WG-Linked unter die farbigen Rollen, die sichtbar bleiben sollen, zum Beispiel VIP, Mods, Supporter oder Nitro.

Discord färbt den Namen eines Mitglieds mit der höchsten Rolle, die eine Farbe hat. Wenn WG-Linked über VIP steht und eine eigene Farbe hat, zeigt ein verknüpfter VIP die Farbe von WG-Linked statt VIP.

WG-Linked bleibt auch unter der Bot-Rolle. Liegt sie über dem Bot, kann der Bot sie nicht vergeben.

Eine sichere Reihenfolge, von oben nach unten:

  1. Server-Inhaber
  2. Admin
  3. WG Link (der Bot)
  4. Team und farbige Rollen, die dir wichtig sind (Mods, VIP und Ähnliches)
  5. WG-Linked
  6. Alle anderen

5. Das Command Center öffnen und Setup speichern

Auf deinem Server /admin oder /link-setup web ausführen. Die Antwort siehst nur du. Öffne den Link und melde dich mit Discord an.

Gehe zu Setup. Für deinen Server lautet die Seite:

https://bot-production-a210.up.railway.app/admin/<deine-server-id>/setup

Der Befehl öffnet bereits den richtigen Server. Die Adresse musst du nicht selbst eintippen.

Stelle das ein und klicke dann Speichern:

  • Verified-Rolle. Die Rolle aus Schritt 3, zum Beispiel WG-Linked.
  • Nick-Stil. Wie ein verknüpfter Name auf deinem Server aussieht. Die Auswahl ist [TAG] Name (EU), Name (EU), [TAG] Name oder nur der Name.
  • Welcome-DM. An oder aus. Wenn jemand diesem Discord beitritt. Nicht die DM nach /link start.
  • Link-DM. Eine private Nachricht, nachdem /link start geklappt hat, mit dem Wargaming-Konto, dem Server-Nick und der Verified-Rolle.
  • Unlink-DM. Eine private Nachricht nach /link unlink, die bestätigt, dass die Verknüpfung entfernt wurde.
  • Fallback-Kanal. Wird benutzt, wenn dieses Mitglied DMs geschlossen hat.

Speichern und Nicks aktualisieren ist für später, wenn du den Nick-Stil änderst und bereits verknüpfte Mitglieder sofort umbenennen willst.

Dieselben Einstellungen gibt es in Discord auch als /link-setup role und /link-setup options. Prüfen kannst du sie jederzeit mit /link-setup status.

6. Einen Verknüpfen-Button für Mitglieder posten

Dieser Schritt ist optional. Im Kanal, in dem Mitglieder ihn finden sollen, /link-panel ausführen.

WG-Link postet eine Nachricht mit einem Button. Der Button startet dieselbe Verknüpfung wie /link start.

WG-Link ist bereit

Für eine normale Einrichtung ist nichts weiter nötig.

Jedes Mitglied entscheidet selbst, ob es verknüpft. Es benutzt /link start oder den Panel-Button, wählt EU, NA oder ASIA und meldet sich bei Wargaming an. Wenn das fertig ist, bekommt es die Verified-Rolle und, wenn Discord es erlaubt, einen Server-Nick wie [GURKA] Player (EU).

Die Antwort ist privat. Nur dieses Mitglied sieht sie. Sie zeigt das verknüpfte Konto, den Server-Nick und /link unlink, wenn die Verknüpfung entfernt werden soll.

Bis ein Mitglied das macht, bleibt es unverknüpft und bekommt die Rolle nicht.

Konfiguracja WG-Link

Dla administratorów serwera, gdy WG-Link jest już na Discordzie. 24 września 2026.

Robisz to raz. Potrzebujesz uprawnienia Zarządzaj serwerem albo Administrator. Gdy te kroki są zapisane, bot jest gotowy. Każdy członek i tak łączy własne konto Wargaming.

1. Pozwól botowi działać

Gdy zapraszasz WG-Link, Discord pyta o dostęp. Zaakceptuj ten ekran.

Bot potrzebuje uprawnień do przeglądania kanałów, wysyłania wiadomości, osadzania linków, czytania historii wiadomości, zarządzania rolami i zarządzania pseudonimami. Bez Zarządzaj rolami i Zarządzaj pseudonimami nie nada roli połączonym członkom i nie ustawi pseudonimów na serwerze.

2. Przesuń własną rolę bota w górę

Otwórz Ustawienia serwera, potem Role.

Discord tworzy rolę dla bota, zwykle o nazwie WG Link. Przeciągnij tę rolę wysoko na liście. Role wyżej na liście są silniejsze.

Ustaw ją nad rolą verified z następnego kroku i nad członkami, których pseudonimy mają się zmieniać. Zwykłe miejsce jest pod właścicielem serwera i twoją rolą Admin, a nad Mods, VIP i wszystkimi innymi.

Bot zmienia pseudonim członka tylko wtedy, gdy jego najwyższa rola jest pod rolą bota. Właściciela serwera nie zmieni nigdy.

3. Utwórz rolę, którą dostaną członkowie

Utwórz nową rolę dla osób, które łączą konto Wargaming. Nazwę wybierasz sam. WG-Linked jest czytelnym przykładem.

To zwykła rola. Jest osobna od własnej roli bota. Nie używaj roli bota jako roli verified.

Członkowie dostają ją po zakończeniu łączenia, albo przez /link start, albo przez przycisk, który później wstawia /link-panel. Oba zaczynają to samo łączenie.

4. Ustaw tę rolę tak, żeby nie zakrywała ważnych kolorów

Przeciągnij WG-Linked pod kolorowe role, które mają zostać widoczne, na przykład VIP, Mods, Supporter albo Nitro.

Discord koloruje nazwę członka jego najwyższą rolą, która ma kolor. Jeśli WG-Linked stoi nad VIP i ma własny kolor, połączony VIP pokazuje kolor WG-Linked zamiast VIP.

WG-Linked zostaw też pod rolą bota. Jeśli jest nad botem, bot nie może jej nadać.

Bezpieczna kolejność, od góry do dołu:

  1. Właściciel serwera
  2. Admin
  3. WG Link (bot)
  4. Ekipa i kolorowe role, na których ci zależy (Mods, VIP i podobne)
  5. WG-Linked
  6. Wszyscy inni

5. Otwórz Command Center i zapisz Ustawienia

Na swoim serwerze użyj /admin albo /link-setup web. Odpowiedź widzisz tylko ty. Otwórz link i zaloguj się przez Discord.

Wejdź w Ustawienia. Dla twojego serwera strona to:

https://bot-production-a210.up.railway.app/admin/<id-twojego-serwera>/setup

Komenda otwiera już właściwy serwer. Nie musisz wpisywać adresu sam.

Ustaw to, a potem kliknij Zapisz:

  • Rola verified. Rola z kroku 3, na przykład WG-Linked.
  • Styl nicku. Jak połączona nazwa wygląda na twoim serwerze. Do wyboru są [TAG] Nazwa (EU), Nazwa (EU), [TAG] Nazwa albo sama nazwa.
  • DM powitalna. Włącz albo wyłącz. Gdy ktoś dołącza do tego Discorda. To nie DM po /link start.
  • DM link. Prywatna wiadomość po udanym /link start, z kontem Wargaming, nickiem na serwerze i rolą verified.
  • DM unlink. Prywatna wiadomość po /link unlink, z potwierdzeniem, że połączenie zostało usunięte.
  • Kanał zapasowy. Używany, gdy ten członek ma zamknięte DM.

Zapisz i zaktualizuj nicki jest na później, gdy zmieniasz styl nicku i chcesz od razu zmienić nazwy już połączonych członków.

Te same ustawienia są na Discordzie jako /link-setup role i /link-setup options. Sprawdzisz je w każdej chwili przez /link-setup status.

6. Wstaw przycisk łączenia dla członków

Ten krok jest opcjonalny. Na kanale, na którym członkowie mają go znaleźć, użyj /link-panel.

WG-Link wstawia wiadomość z przyciskiem. Ten przycisk zaczyna to samo łączenie co /link start.

WG-Link jest gotowy

Do zwykłej konfiguracji nic więcej nie trzeba.

Każdy członek sam decyduje, czy się łączy. Używa /link start albo przycisku na panelu, wybiera EU, NA albo ASIA i loguje się w Wargaming. Gdy to się skończy, dostaje rolę verified i, jeśli Discord na to pozwala, nick na serwerze taki jak [GURKA] Player (EU).

Odpowiedź jest prywatna. Widzi ją tylko ten członek. Pokazuje połączone konto, nick na serwerze i /link unlink, jeśli chce usunąć połączenie.

Dopóki członek tego nie zrobi, zostaje niepołączony i nie dostaje roli.
