1. What the service does

WG-Link is a Discord bot for linking Discord accounts with Wargaming / World of Warships accounts. It can be used on more than one Discord server. In particular, the bot can:

  • start a verification on each server (choose a region, Wargaming login),
  • store a successful link for that server,
  • change the server nickname (the style is selectable, for example [CLAN] Name (EU) or Name (EU)),
  • assign a verified role on that server,
  • give admins and mods management tools (/link-setup, /link-panel, /link-check, /role-admin, /help, and others).

A link on server A does not apply automatically on server B. Members have to link again on each server. One Wargaming account may belong to only one Discord account.
